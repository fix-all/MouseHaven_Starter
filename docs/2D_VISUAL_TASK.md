## 视觉与交互约束

- 默认微型观察口仍是 40×40 逻辑像素，可比较 32/48/64。展开窗口仍是 480×270、16:9；提供 1×/2×内部镜头倍率对比，世界状态和动作时间不随切换重置。
- 家园镜头只在窗口内跟随角色；窗口锚点不漂移。展开时重新渲染当前视口，不放大微型截图。
- 场景正式模式使用独立侧视像素素材：小屋、空/有胡萝卜菜地、花圃。几何场景保留为可切换的调试模式。不得把斜视/等距图直接冒充横版侧视资源。
- 角色素材记录 sourceRect、原生比例、统一脚底根节点、嘴部接触点和装备状态。图集切分不能混入邻帧；不同动作不能靠平移同一张图假装有真实新帧。
- 角色、文件夹、作物与碎屑分别绘制。啃咬只改变本程序表面的视觉效果，不读取或修改真实桌面文件与系统图标。
- 素材在启动时加载和缓存，静止时停止无意义的帧绘制。绘制后端与核心状态分离。
