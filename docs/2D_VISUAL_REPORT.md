# 横版 2D 视觉闭环实施与验证记录

日期：2026-09-24。此版本完成一段可运行的侧视生活与外出演出，仍是**待真实桌面验收的试用版**，不代表最终美术或正式发布。GitHub 上的 `v0.1.0-p0` 可执行预发布仍是旧版；本报告对应的新自包含 Release 程序尚未作为 GitHub Release 附件发布。

## 本轮变化

- 同一 `WorldState` 增加朝向、菜地状态、固定模拟文件夹位置与咬痕状态。家中按“小屋入口→指定菜地→两帧干活→胡萝卜出现→回入口”循环；外出/返回仍由同一只鼠鼠完成。
- 角色图集用逐帧 sourceRect、原生比例、背包状态、脚底根节点和啃咬嘴部锚点。旧图集 x=1330 的尾巴串格帧不再使用。家中走路/干活与桌面走路/跑步/啃咬均有真实不同帧；左右朝向使用缓存镜像。
- 小屋、空/有胡萝卜菜地、花圃与模拟文件夹分别缓存为独立像素资源。几何画法保留为托盘“侧视像素场景”的调试对比选项。
- 480×270 展开窗口有 1×/2× 内部镜头倍率；默认 2×。微型仍默认 40×40，可试 32/48/64。家园/桌面的角色位置以同一个脚底根节点换算；文件夹不因啃咬而隐藏或换尺寸，咬痕画在自身表面。
- 图片只在启动时读取嵌入资源并生成缓存，绘制循环不读图。没有访问真实桌面目录、文件内容或系统图标。

## 仍需真实桌面验收

`2D_VISUAL_ACCEPTANCE.md` 的视觉/交互条目尚未由真实用户桌面逐项执行，状态仍为“未测试”。尤其需要确认：实际尺寸下 40×40 可辨认度，1×/2× 展开体验，左/右动画播放、点击透明区域、外出交接与回程、文件夹咬痕连续性、托盘退出，以及 100%/150%/200% DPI。需录制实际运行并分别采样活跃、静止、暂停和隐藏场景的 CPU、工作集、GDI 与系统合成开销。

素材仍是 AI 辅助生成并经代码切分的试用资源，作物只有空地/胡萝卜两种视觉状态；没有正式逐像素定稿、真实文件操作、随机外出或最大化 2.5D。缺口已在 `assets/README.md` 标出。
