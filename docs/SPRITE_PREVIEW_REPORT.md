# P0 鼠鼠新素材版记录

日期：2026-09-24。此版本把 `assets/previews/mouse-p0-v2-preview.png` 接入既有 P0 绘制层，默认使用新动作图，托盘可切回原几何鼠鼠；共用同一 `WorldState`、行为时钟和家园/桌面窗口。未增加 2.5D 或真实桌面文件访问。

## 实现

- 图片作为程序集资源嵌入，启动时从 4×2 素材表一次性生成八个 36×36 预乘 Alpha 缓存帧；绘制循环不重新读盘。
- 缩小时使用近邻取样；本地离屏预览显示其轮廓比平滑缩放更清楚。输出保留为 `assets/previews/mouse-p0-v2-*-render*.png`，这些是绘制器样本，不是桌面截图。
- 家中使用待机、两帧走路、种植工作；桌面使用背包走路、模拟文件夹啃咬、受惊、回家冲刺。切换画法不改变动作进度或角色所有权。
- 素材版啃咬帧自带虚拟文件夹，因此该动作期间隐藏单独的模拟文件夹窗口，避免同屏出现两个文件夹。所有文件与图标操作边界不变。
- 素材版啃咬画面静止时停止帧定时器；点击受惊时重置单调时钟基线，避免长时间静止后跳过受惊动作。
- 保留原几何绘图作为托盘对比模式；新预览图尚不是规范切图完成的正式像素素材。
